# 姬忠宽商业影像作品集网站

React + TypeScript + Vite 个人作品集，展示姬忠宽的摄影、摄像、商业内容制作、项目策划与 AI 协作能力。

## 本地运行

```bash
npm ci
npm run dev
```

打开开发服务输出的地址，通常为 `http://localhost:5173/`。建议使用 Node.js 24.15 或更新的兼容版本。

## 验证与构建

```bash
npm test -- --run
npm run build
```

构建结果在 `dist/`。部署时使用 `npm ci` 安装、`npm run build` 构建，并将 `dist` 作为静态网站目录。上传源码到 GitHub 不会自动部署网站；构建产物需由网站托管服务发布。

## 更新作品

- 真实项目文案集中在 `src/data/portfolioData.ts`。
- 作品预览图或视频放入 `src/assets/`，并遵守该目录中的媒体替换说明。
- 首页组合原创金属视觉与个人 3D 风格卡通形象；项目卡展示作品静帧，保持完整构图。
- 依赖目录、构建产物、内部配置和分析预览由 `.gitignore` 排除，不提交到仓库。

## 当前重点

《青红厨师2》单独展示微综艺全案策划与 AI 实践：前期准备、AI 片头与漫画、vibe coding 工具和现场执行协同。其他服务覆盖品牌产品、活动展会、人物口播、课程、直播与商业短内容、摄影和后期制作。
